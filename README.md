# wolf_embodied

A Unity-based embodied intelligence project  
featuring a 2.2m wolf-like agent with >40 DOF articulation  
trained using custom RL (eventually SAC / PPO).  

### Features
- Unity ArticulationBody rig (hips, spine, chest, neck...)
- Python ML-Agents Low-Level API (no built-in trainer)
- Custom policy network (PyTorch)
- Live inference loop with observations + actions
- Experimental reward shaping for balance

### Goals
- biologically-inspired control
- realistic balance
- RL + SNN + LNN in later stages
